#### Tech Stack and technical approach

Since I'm a fan of backend and infrastructure engineering, I will be focusing more on actual tool development logic and not on visuals, nor I will lose time on try to develop an UI or web tool that tries to achieve something that a Python CLI tool could do easily.

I'm interested in CLI tools since I work with Linux Ubuntu a lot, and I'm going to set up the environment and packages using `Poetry` which is very usefull when managing packages (https://python-poetry.org/) and use the `Click` package for the CLI.
